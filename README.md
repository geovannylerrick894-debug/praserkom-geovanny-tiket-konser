# Website Pemesanan Tiket Event

## Deskripsi
Website Pemesanan Tiket Event adalah aplikasi berbasis web yang dibuat menggunakan Laravel. Website ini digunakan untuk melihat daftar event dan memesan tiket sesuai kategori event yang tersedia.

## Fitur
- Menampilkan daftar event.
- Memfilter event berdasarkan kategori Music, Festival, dan Seminar.
- Menampilkan informasi dan harga tiket event.
- Memesan tiket berdasarkan jumlah yang diinginkan.
- Mengisi informasi pemesan berupa nama dan email.
- Mengelola data event melalui dashboard admin.
- Mengelola dan melihat pesanan tiket.

## Teknologi
- Laravel
- PHP
- MySQL
- HTML
- Tailwind CSS
- JavaScript

## Pengguna
- Customer: Melihat event dan melakukan pemesanan tiket.
- Admin: Mengelola data event dan pesanan tiket.

## Tujuan
Website ini dibuat untuk mempermudah pengguna dalam mencari event dan melakukan pemesanan tiket secara online, serta membantu admin mengelola informasi event dan pesanan dengan lebih mudah.
